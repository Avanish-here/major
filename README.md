# Disaster Management System

A comprehensive web application designed to assist in disaster response and management. This system provides real-time alerts, interactive maps, emergency contacts, and data visualization to help communities and responders coordinate during natural disasters and emergencies.

## Features

- **Dashboard**: Overview of current disaster situations and key metrics
- **Interactive Maps**: Real-time mapping of disaster zones using Google Maps and Leaflet
- **Alerts System**: Receive and manage disaster alerts and notifications
- **Emergency Contacts**: Quick access to important contact information
- **Data Download**: Export disaster-related data for analysis
- **User Authentication**: Secure login and signup functionality
- **Responsive Design**: Optimized for desktop and mobile devices

## Tech Stack

- **Frontend**: React 18 with TypeScript
- **Styling**: Tailwind CSS
- **Maps**: React Google Maps API and Leaflet
- **Routing**: React Router DOM
- **Icons**: React Icons
- **Build Tool**: Vite
- **Development**: Hot module replacement with Vite

## Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   cd disaster-management-system
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to `http://localhost:5173`

## Usage

- Navigate through the app using the navbar
- View the dashboard for an overview
- Use the map page to visualize disaster areas
- Check alerts for real-time notifications
- Access emergency contacts when needed
- Download relevant data from the download page

## Build for Production

To build the app for production:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
